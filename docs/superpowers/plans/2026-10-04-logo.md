# Logotip — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ikkala ilovada Hisob24 logotipi: tab ikonlari, qobiq (sidebar, topbar), login va qolgan to'liq ekranlar. Funksiya o'zgarmaydi.

**Architecture:**
- `components/logo.tsx`: inline SVG, `fill="currentColor"`. `Logo` ("Hisob24" yozuvi, `img` "Hisob24") va `LogoMark` ("H24", bezak). Yo'llar dizayner faylidan aynan, `viewBox` chegaraga qirqilgan.
- Rang `--brand` tokenidan (`text-brand`): light `#174449`, dark oq, Telegram ichida chat matn rangi.
- Tab ikonlari Next fayl konvensiyasi bilan: `app/icon.svg`, `app/apple-icon.png`, `app/favicon.ico`; `proxy.ts` ularni sessiyasiz o'tkazadi.
- Umumiy fayllar avval `apps/web` da testlari bilan yoziladi, keyin `apps/admin` ga aynan ko'chiriladi (oxirida `cmp`). Admin'ning o'z bo'lagi: `Brand` (logotip + "Admin").

**Tech Stack:** Next 16 (App Router), Tailwind v4, shadcn `base-nova` (@base-ui/react), Vitest + RTL + MSW, Playwright.

Manbalar: qarorlar va dizayn `docs/superpowers/specs/2026-10-04-logo-design.md` da. Dizayner fayllari: `~/Downloads/Telegram Lite/` (`Hisob24_brand_svg.svg`, `H24 512x512.svg`).
