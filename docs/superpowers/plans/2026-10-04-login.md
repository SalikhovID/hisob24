# Login dizayni: brend paneli — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ikkala ilovaning brauzerdagi `/login` i brend paneli bilan: keng ekranda panel va forma yonma-yon, telefonda panel tepada tasma. Funksiya o'zgarmaydi.

**Architecture:**
- `components/login/login-frame.tsx`: `header` (panel: `h1` da brend, tavsif, fonda `Logo24`) va `main` (forma). Ikkala ilovada bir xil nusxa; web `Logo` ni, admin `Brand` ni beradi.
- Rang ikki tokendan: `--brand-panel`, `--brand-panel-foreground`. Panel ichida `--brand` va `--muted-foreground` qayta belgilanadi, shuning uchun `Logo` va `Brand` o'zgarmaydi.
- `components/login/code-field.tsx`: olti katakli kod, ikkala login uchun bitta.
- Umumiy fayllar avval `apps/web` da testlari bilan yoziladi, keyin `apps/admin` ga aynan ko'chiriladi (oxirida `cmp`).

**Tech Stack:** Next 16 (App Router), Tailwind v4, shadcn `base-nova` (@base-ui/react), `input-otp`, Vitest + RTL + MSW, Playwright.

Manbalar: qarorlar va dizayn `docs/superpowers/specs/2026-10-04-login-design.md` da.
